# Miryo Document Reader

**Freedom through technology. ❤️**

Miryo Document Reader is an open-source local document-reading plugin for Claude Code, developed as part of the independent **MiryoLove** project.

The project provides document text extraction through a local Python utility, allowing Claude Code to read and analyze supported files.

### Supported formats

- TXT
- DOCX
- XLS
- XLSX
- PDF (documents with extractable text)

### Features

- Local document processing
- Extraction of text, paragraphs and tables
- Spreadsheet worksheet extraction
- PDF text extraction
- Original files are never modified by the reader
